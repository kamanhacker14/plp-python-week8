# Personal Mini-Toolkit

## What it does
A menu-driven Python program with four tools. The menu keeps coming back after every tool until you choose Quit, and invalid choices get a polite message instead of crashing the program.

1. **Number Guessing Game** - guess a secret number from 1 to 20 with higher/lower hints.
2. **To-Do List** - add, view and remove tasks (the list is remembered while the program runs).
3. **Simple Calculator** - add, subtract, multiply or divide two numbers (handles division by zero and bad input).
4. **Name Formatter** - shows your name neatly formatted, in capitals, as initials, and its length.

## How to run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder and run:

```
python toolkit.py
```

(On some systems use `python3 toolkit.py`.)
